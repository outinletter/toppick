# 1~3개월 연구 엔진

기본 화면은 `mediumTerm.items`를 사용합니다. 기존 `top3`와 `items`는 단기 비교용 API로 유지합니다.
중기 후보는 단기 최종 20종목으로 제한하지 않고 시장별 유동성/자료 필터를 통과한
전체 분석 후보에서 선정합니다. 종목군 자체는 기존 수집 후보군이므로 전체 상장종목 백테스트가 아닙니다.
상위 10개 이내, 동일 업종 최대 2개이며 업종 미상도 한 그룹으로 제한합니다.

가중치: 실적 25, 리포트 15, 재무 15, 상대가치 15, 업종 10, 60일 추세 10,
잉여현금흐름 5, 외국인/기관 20일 동반 수급 5점. 위험 점수를 차감합니다.
각 구성요소를 상한 안으로 제한하며 누락 비중을 다른 항목으로 재분배하지 않습니다.
기존 구성요소를 활용한 고정 연구 가중치이며 최적화나 확률 보정은 수행하지 않았습니다.

20/40/60거래일 관찰, 5거래일마다 재검토, 최대 60거래일 관찰 정책입니다.
실제 매도/보유 자동 집행은 없습니다. 증권사 목표가는 만기가 확인되지 않아
중기 목표가격으로 사용하지 않습니다. 중기 목표가/손절가/상승확률은 미설정(null)입니다.

각 생성 결과와 요인값을 reports/medium-term-snapshots에 실행별 보존합니다.
매 추천 생성 시 이전 스냅샷을 추적합니다. 한국시간 생성일 이후 첫 시장 거래일 시가에
가상 진입하고 20/40/60번째 시장 거래일 종가로 평가합니다. 같은 날짜/종목은 최초 스냅샷만
집계합니다. 당일 미완성 봉은 제외하고, 필요한 종목 봉이 빠지면 성과를 산출하지 않습니다.
비용은 왕복 30bp 가정이며 실제 세금/스프레드/슬리피지를 보정한 값은 아닙니다.
순수익률, 시장 가격지수 대비 초과수익률, 종가 기준 최대낙폭을 제공합니다.

제약: 현 수집기의 수정주가와 지수 사용, 배당 재투자/상장폐지 수익률/거래정지 체결/수정 이력은
별도 검증이 필요합니다. 금융·컨센서스의 과거 시점 자료와 실적 추정 변경 이력이 충분하지 않습니다.
분기 실적 원본의 성장 전망과 실제 애널리스트 추정치 수정은 동일하지 않습니다.
과거 미사용 구간 검증이 없으므로 모든 후보는 연구·관망이고 productionEnabled=false입니다.
성과 관측이 쌓여도 자동으로 운영 승격하지 않습니다. 기존 실패한 단기 holdout은 재사용하지 않습니다.
