## 판단 구조

가격 상승 가설은 **정보 변화에 따른 재평가, 지속적 매수 수요, 거래량이 동반된 가격 돌파**로 나누고, 시장·업종·위험·체결 조건이 이를 지지하는지 확인한다. 지표를 많이 더해 높은 점수를 만드는 방식은 사용하지 않는다.

| 모듈 | 구현한 판단 | 현재 연결 상태 |
|---|---|---|
| 시장 환경 | 지수 5/20일 수익률, 20일 변동성, 추세 | 일봉 연결 |
| 업종 | 동일 업종 구성 기준에서 시장 대비 5/20일 상대 수익률과 지속성 | 날짜 있는 입력 어댑터 구현, 실제 이력 미연결 |

| 체결 가능성 | 호가 자체 시각, 수집 시각, 스프레드, 거래 상태·시장 | 입력 어댑터 구현, 실시간 호가 미연결 |

가격 모멘텀과 실적 정보 변화는 별개로 검토할 연구 가설이다. [Momentum Strategies 원논문](https://www.nber.org/system/files/working_papers/w5375/w5375.pdf)은 이 설계의 참고 근거이며, 한국 주식 1~3일 순수익 10%의 성능 증거가 아니다.

돌파·수급·실적 정보의 서로 다른 근거군 중 최소 2개를 초기 확인 조건으로 사용한다. 실적 상향과 실적 서프라이즈는 같은 정보군으로 묶어 중복 계수하지 않는다. 근거군들이 통계적으로 독립이라는 의미는 아니다. 보고서의 순서는 근거군 수 및 시장 대비 모멘텀 순이며 예측 확률 순위가 아니다.

시장 방어 국면, 낮은 유동성, 과도한 구조적 손실, 악재, 공시/업종/공매도/호가 미확인, 종목 마스터·시장 범위·기업행동 미검증은 진입 차단 사유로 남긴다. 데이터가 비어 있으면 0점/중립/호재로 대체하지 않는다. 모든 조건이 충족되어도 미검증 모델은 연구 후보로만 출력한다.

## 초기 정책: 학습된 최적값이 아님

- 최소 61개 일봉, 평균 거래대금 50억원, 거래량 배수 1.5를 초기 연구값으로 사용한다.
- 기준 손절가는 `min(최근 5일 저가, 종가 - 1.5 × ATR14)`이다. 손실이 큰 종목을 임의로 손절폭 축소해 통과시키지 않는다. 비용 포함 구조적 위험 8% 초과는 차단한다.
- 종가 기준 가정 매수가에 왕복 비용 0.35%, 편도 슬리피지 KOSPI 0.10%/KOSDAQ 0.20%를 반영한다. 이는 비교용 비용 시나리오이며 실제 수수료·세금·체결 충격 검증값이 아니다.
- 목표가는 `가정 매수가 × (1 + (10 + 왕복비용%)/100) / (1 - 매도슬리피지율)`이다. 실제 다음 거래일 시가·호가에서 다시 산출해야 한다.
- 위험 예산 0.25%, 포지션 상한 5%, 일평균 거래대금 참여 상한 0.1%는 표시용 초기 정책이다. 계좌 잔고, 종목 간 상관, 체결량을 반영한 포트폴리오 주문 기능이 아니다.

## 데이터 계약과 감사

입력 공통: `source`, 시간대가 포함된 `collectedAt`, 가능하면 `publishedAt`. 실제 이용 가능 시점은 두 시각 중 늦은 시각이다. 당시 수집하지 못한 최신 수정 자료를 과거 시점에 주입하지 않는다. 일봉은 해당 일자 16시 이후 자료만 사용한다. 이 마감 규칙은 통합 KRX/NXT 거래 달력을 대체하지 않는다.

추가 자료 경로: `reports/independent-upside/supplements.json`. 최상위 키는 6자리 종목 코드, 값은 다음 모듈별 envelope이다. 공통 시각·출처와 함께 아래 필드를 공급한다.

| 키 | 필수 데이터 |
|---|---|
| flow | `unit: KRW`, `rows`: 20일 이상 `date(YYYYMMDD)`, `foreignNetKrw`, `institutionNetKrw`, `pensionNetKrw`, `trustNetKrw` |
| revisions | `rows`: `broker`, `fiscalPeriod`, `metric(EPS/operatingProfit/revenue/targetPrice)`, `currency`, `unit`, `value`, `publishedAt` |
| events | `rows`: `sourceId`, `type`, `publishedAt`; 실적은 `actual`, `consensus`, `consensusPublishedAt`, `comparableBasis: true` |
| quote | `quoteAt`, `bid`, `ask`, `venue`, `tradingStatus: TRADING`; 호가 시각과 수집 시각 모두 60초 이내 |
| sector | `sectorId`, `membershipAsOf(YYYYMMDD)`, `rows`: 21일 이상 `date`, `sectorClose`, `marketClose` |
| shortPressure | `ratioUnit: percent`, `rows`: 5일 이상 `date`, `shortTurnoverPct`; 선택 `balanceRows`의 `shortBalancePct`, `lendingRows`의 `lendingBalanceShares`, 각각 `date` |

현재 수급은 기관 하위 주체 필드의 누락을 검사하지만 연기금/투신별 지속성 모델까지 학습하지 않았다. 목표주가 변화는 비교 가능한 변화만 보고하며 매수 근거로 단독 사용하지 않는다. 공매도 증가를 자동 악재 또는 숏스퀴즈 호재로 단정하지 않는다.

시장 목록 응답과 종목별 조회 어댑터 자료는 `reports/independent-upside/raw/<수집시각>/`에 보관한다. 분석은 입력 SHA-256, 정책, 추가 자료, 판단 시각을 `snapshots/`에 저장한다. 키움 HTTP 원문 전체를 저장하는 기능은 아니다. 신규 수집부터 `input.json`도 같은 원본 디렉터리에 복제한다. 추가 자료는 결과 스냅숏에 포함하므로 이후 변경과 구분할 수 있다.

현재 목록의 우선주/SPAC 제외는 명칭과 제공자 분류에 의존한다. 시점별 공식 보통주 마스터, 상장폐지/정지, 기업행동, 거래소별 범위는 아직 검증하지 못했으므로 각각 차단 사유를 유지한다. 네이버 거래대금과 키움 일봉 거래대금의 일부 차이가 관찰되어 동일 시장 범위 대조도 필요하다. 현존 종목 목록으로 과거 종목군을 소급 구성해서는 안 된다.

## 새 확률 엔진으로 이어지는 절차

1. **원천 연결**: 거래소 범위와 기업행동이 맞는 종목 마스터·가격·분봉·호가를 우선 확보한다. 수급 세부 원본, 당시 컨센서스 이력, 최초/정정 공시 시각, 업종 구성 이력, 공매도/대차 기준일도 연결한다. 공급자 자격·접근 권한이 필요한 컨센서스 이력은 현재 확보되지 않았다.
2. **라벨 정의 고정**: 다음 거래일 체결 가능 가격에 진입하고 1/2/3거래일 내 비용 차감 +10% 선도달, 손절 선도달, 미도달을 구분한다. 익절·손절 동일 일봉이면 분봉으로 순서를 확인하고 불명확하면 손절 우선으로 처리한다. 거래정지·상폐·갭·미체결도 포함한다.
3. **별도 학습 자료**: 새 엔진의 특징과 구조적 손절로 라벨을 다시 만든다. 이미 결과를 확인한 기존 95개 테스트 표본은 최종 미사용 검증으로 재활용하지 않는다. 새 자료의 학습/검증/최종 테스트 날짜·특징·비용·정책·해시를 결과 열람 전에 고정한다.
4. **모델 비교**: 훈련 기본빈도, 규제 로지스틱 모형, 일자별 경쟁위험 모형부터 비교한다. 특징군을 하나씩 제거해 개선 기여를 검증하고, 기간별 목표/손절 확률을 보정한다. 새 독립 특징용 학습기는 아직 구현·학습하지 않았다.
5. **시간 분리 평가**: 무작위 행 분할 대신 날짜 순 walk-forward, 라벨 중첩 제거와 embargo를 사용한다. 같은 날 종목·업종 상관을 반영한 날짜 단위 불확실성 구간, 목표/손절 Brier, 보정 오차, 비용 후 기대수익, 꼬리손실, 거래 가능 수를 비교한다. 비용 2배와 더 불리한 체결에서도 확인한다.
6. **운영 전환 조건**: 새 미사용 자료에서 단순 기준보다 확률 품질이 좋고 선택 거래 기대수익의 하한이 양수이며 손실·유동성 한도를 지킨다는 증거가 필요하다. 표본은 여러 시장 국면과 충분한 목표 도달 사건을 포함해야 한다. 통과 전에는 추천 확률을 만들어 표시하지 않는다.

## 검증 결과와 한계

Python 전체 회귀검사 37건 통과(독립 엔진 13건 포함). 기존 점수 변경 무영향, 미래 자료 차단, 결측 거래량, 다른 회계기간 비교 금지, 사후 컨센서스 차단, 오래된 호가 재수집, 순수익 목표 계산, 누락 업종/공매도 구분을 확인했다. 실제 30종목 수집/분석도 실행했다. 이 검사는 소프트웨어 동작 검증이며 예측 수익성 검증이 아니다.

별도 기존 스냅숏 비교 실험은 5개 진입일의 95건에서 3일 목표 선도달 8건, 손절 선도달 52건이었다. 목표 확률 Brier가 기본빈도보다 개선되지 않아 운영 승격하지 않았다. 이 결과를 독립 엔진의 성능으로 해석하지 않는다.
