# 중기 예측 신뢰도 점검과 필요한 데이터

## 2026-09-22 수정

- medium-term-v2: 리포트 키워드에서 추정한 실적 상향 점수를 중기 실적 점수에서 제거.
- 기존 DART 전체 재무제표 응답에서 전년 같은 기간 영업이익/매출, 영업현금흐름,
  자본/부채, 접수번호와 공시일, 결산일, 수집 시각을 추출.
- 분/반기 손익계산서는 thstrm_amount와 frmtrm_q_amount를 비교하고 연간 보고서는
  frmtrm_amount를 비교. 현금흐름은 누적 금액으로 표시하며 잉여현금흐름으로 부르지 않음.
- 결측·비정상 숫자·미래 공시·오래된 가격/수급에는 가점 없음. 결측 가중치를 재분배하지 않음.
- DART 재무 출처, 유효한 가격, 양의 자본, 위험 입력, 가중 자료 충족도 60% 이상을
  후보 포함 조건으로 사용. 자료 충족도는 승률이나 상승 확률이 아님.
- 20일뿐 아니라 60일 순매수 방향까지 확인. 업종 미확인은 0점 관측과 구분하여 결측 처리.
- 전 후보의 점수·충족도·누락/차단 사유를 결과의 dataQuality.candidateAudit에 보존.
- v1/v2의 전향 성과 표본을 분리. 데이터 이용 가능 시각은 계산 완료 시각으로 기록.

가격/수급 7일, 리포트 90일, 분기 재무 210일, 연간 재무 450일은 보수적 연구 기본값이며
거래소 달력과 성과 검증으로 보정해야 한다. 장기휴장 시 7일을 넘는 자료는 후보에서 제외될 수 있다.
리포트 목표가와 PER/PBR는 여전히 보조 자료이며 목표가의 1~3개월 만기는 검증되지 않았다.

## 추가 API 우선순위

| 우선 | 자료 | 필요한 필드 | 현재 상태 |
|---|---|---|---|
| 1 | 과거 시점별 컨센서스/증권사별 추정치 | code, fiscalPeriod, EPS/영업이익/매출 추정치, broker, publishedAt, availableAt, revision/version | 미연결. FnGuide/FnSpace 등 제공사에 과거 날짜 조회 및 이용 권한 확인 필요 |
| 2 | 기업행동·상장폐지 포함 과거 종목군 | 상장/상폐일, 거래정지, 배당, 분할/병합, 유상증자, 수정계수 적용일/공개일 | 생존편향 없는 검증용 원본 미확보 |
| 3 | 거래일 달력·업종 이력·유통주식수 | 거래일, 효력일, 과거 업종 분류, 일별 시가총액/유통주식수 | 날짜별 정규화/보존 보완 필요 |
| 4 | 대차잔고·공매도·투자자별 일별 원본 | 기준일, 실제 공개시각, 단위, 투자자 분류, 잔고 | pykrx 수급/공매도 사용, 대차는 미연결 |

현재 키움/DART/KRX 접속 정보는 재사용한다. DART 실적 보완을 위해 새 인증키는 필요 없다.
사용자 요청에 따라 유료 데이터 신규 구독은 진행하지 않는다. 2026-09-22 실행에서
KRX 세션 초기화가 JSONDecodeError로 실패했으며, available=false로 보고하고 수급 가점에서 제외했다.
외부 로그인 응답 정상화는 미확인이다. 데이터 수집 정상화와 단순 오류 처리 성공을 구분한다.
컨센서스 API가 현재값만 제공하면 과거 시점 검증 문제는 해결되지 않는다. API 명세와
샘플 응답, 이용 가능한 과거 범위, 파생 결과의 공개 서비스 사용 권한을 확인한 뒤 연결해야 한다.
새 인증키는 Git에 포함되지 않는 key/ 아래에 저장하며 채팅/코드/브라우저에 넣지 않는다.

공식 자료:
- https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS003&apiId=2019020
- https://fnspace3.fnguide.com/Customer/Info
- https://openapi.krx.co.kr/contents/OPP/MAIN/main/index.cmd

## 성과 검증 한계

기능/데이터 검사 통과는 예측 성과 개선의 증거가 아니다. 과거 미사용 시계열 구간에서
20/40/60일 겹침을 제거한 분할, 최소 60거래일의 평가 경계 간격, 상장폐지 포함 종목군,
비용/거래정지 체결, 업종·시장 초과성과, 최대낙폭, 독립 기간별 안정성 검증이 필요하다.
현재 전향 추적은 같은 종목의 서로 다른 날짜 관측이 겹칠 수 있으므로 독립 표본 수로 보지 않는다.
현재 periodEnd는 사업연도와 보고서 코드로 계산한 12월 결산 기준 추정일이다.
비12월 결산 법인과 정확한 공시 시각은 별도 검증이 필요하며 과거 시점 재현에 그대로 쓰지 않는다.
자동 운영 승인과 확률 출력은 계속 비활성화한다. 기존 실패한 단기 검증 구간을 중기 튜닝에 재사용하지 않는다.
