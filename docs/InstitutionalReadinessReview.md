# 기관급 추천 시스템 보완 검토 및 수정

2026-09-21. 대상: 기존 추천 엔진과 독립 근거 엔진의 결합 정책.

## 판단

현재 프로그램은 연구용 추천 시스템이다. 기관급 수익성과 안정성을 입증했다고 볼 수 없다. 기존 10% 비교 모델은 테스트 진입일 5개, 95건 중 목표 선도달 8건·손절 선도달 52건이며 목표 확률이 단순 기본빈도보다 개선되지 않았다. 이 결과를 새 추천 정책의 성능으로 가져올 수 없다.

우선순위는 임의 지표 추가보다 **시점별 원천 자료, 독립 검증, 체결 비용·손실 통제, 재현성과 장애 감시**이다. [연준의 모델 위험 관리 지침](https://www.federalreserve.gov/frrs/guidance/supervisory-guidance-on-model-risk-management.htm)의 모델 한계·검증·지속 감시 원칙을 검토 기준으로 참고했다. 이 프로그램에 대한 규제 적합성 인증이나 성능 보증을 의미하지 않는다.

## 확인한 결함과 수정

| 문제 | 수정한 동작 |
|---|---|
| 보고서를 다시 분석하면 원천 자료보다 유효기간이 길어질 수 있음 | 원천 수집/공표 시각의 늦은 값 `sourceAvailableAt` 보존, 원천 기준 24시간 검사 |
| 보고서 파싱과 파일 해시 사이 파일 교체 가능 | 동일 바이트로 파싱과 SHA-256 계산 |
| 숫자 변환 오류로 추천 전체 중단 가능, NaN 손익비 기준으로 검사 우회 가능 | 유한 숫자·자료형·RSI/거래대금 범위 검사, 잘못된 값은 진입 차단 |
| 비용 가정에 근접한 작은 수익 여유를 통과시킴 | 수수료/비용과 슬리피지 각각 2배 시나리오의 순손익비 추가 검사 |
| TOP3에 같은 업종 3개가 들어갈 수 있음 | 같은 업종 최대 2개, 업종 미확인도 한 그룹으로 처리 |
| 수집 실패가 로그에만 남아 후보 제외 편향 확인이 어려움 | 요청·분석·제외·실패 수 및 실패 종목/HTTP 상태를 결과에 저장 |
| 코드가 바뀌어도 같은 공식 이름만으로 결과를 비교 | 판단·수집·검증 8개 파일 해시와 합성 모델 식별자 기록, 실행 중 변경 감지 |
| 실제 데이터 확보 범위를 파악하기 어려움 | 선정 후보와 모듈별 확보 수, 확보율을 기록하고 웹에 표시 |
| 중복 자동 갱신이 기존 작업 진행 상태를 실패로 덮어씀 | 실행 중 HTTP 409 응답, 경쟁 작업의 실패 상태 덮어쓰기 방지 |
| 장중 목록 정렬 변화로 페이지 사이 종목 중복/누락 | 최대 3회 재조회·코드 합집합, 확보 수 대조, 미완료 시 새 입력 게시 중단 |

목록 재조회는 실제 장중 장애를 재현한 뒤 수정했다. 1차 진단에서 코스피 2,480개 중 2,479개, 코스닥 1,818개 중 1,813개만 확보됐다. 수정 후 실제 수집에서 코스피 2회 조회로 2,480개, 코스닥 1회로 1,818개를 확보했다. 동일 시점의 공식 전체 종목 집합이 검증됐다는 뜻은 아니다.

새 정책은 `short-term-v5-governed-evidence`, 위험 정책은 `entry-risk-v2-cost-stress`다. 이전 검증 실적과 구분한다. 자동 매매는 추가하지 않았다.

## 기관급 성능을 위해 남은 작업

### 자료 보관 기간과 판단 유효기간

모든 원천을 최근 3개월로 잘라 삭제하지 않는다. 단기 판단의 가격·거래량은 최근 1~3개월을 중심으로 하되 비교용 장기 이력과 과거 검증 자료는 보존한다. 수급은 5/20/60거래일, 실적은 최신 발표와 전년 동기 비교, 호가는 초·분 단위 최신성을 따로 관리한다. 최근 공시 촉매와 아직 해소되지 않은 과거 악재도 구분해야 한다. 과거 미사용 자료 검증에는 그 시점까지 공개·수집 가능했던 값만 입장시킨다.

현재 구현의 원천 24시간 제한은 독립 가격 자료가 재분석으로 갱신된 것처럼 보이는 것을 막는 운영 제한이다. 모든 금융 자료의 유효기간이 24시간이라는 뜻이 아니다. 공식 거래일 달력과 자료별 공표 주기·사건 해소 이력을 연결하는 작업은 남아 있다.

| 우선순위 | 필요한 보완 | 완료를 판단할 증거 |
|---|---|---|
| P0 | 상장폐지·정지·기업행동·수정주가·거래소 범위를 포함한 시점별 종목 마스터와 원천 이력 | 당시 종목군 재현, 원본/정정 버전·시각 보존, 복수 제공처 대조 |
| P0 | 컨센서스 변화·최초 공시·기관 세부 수급·업종 구성·공매도/대차 이력 | 해당 시점에 실제 이용 가능했던 입력, 누락·공표 지연·정정 처리 검증 |
| P0 | 새 정책용 미사용 데이터 검증 | 결과 열람 전 정책 고정, 시간 순 학습/검증/테스트, 라벨 중첩 제거, 단순 기준 대비 확률·기대수익 개선 |
| P0 | 체결 가능성 및 비용 실증 | 호가·분봉·거래량과 실제 비용 기반의 갭, 미체결, 슬리피지·충격 분석 |
| P1 | 포트폴리오 위험 모델 | 종목/업종 비중, 상관·중복 보유, 위험 예산, 회전율, 낙폭과 손실 꼬리 검증 |
| P1 | 운영 감시와 복구 | 데이터 지연·결측·분포 변화 및 확률 보정 열화 감시, 장애 알림·재시도·버전 복구 절차 |

새 검증은 무작위 행 분할 대신 날짜 순으로 나누고, 같은 날 종목 간 상관을 반영한 불확실성 구간을 보고해야 한다. 목표/손절 확률의 Brier·보정 상태, 비용 후 기대수익, 손실 꼬리, 거래 가능 표본 수를 함께 비교한다. 이미 확인한 95개 테스트 사례는 새 최종 테스트로 재사용하지 않는다.

현재 비용 0.35%와 슬리피지는 연구 가정이다. 2배 스트레스 통과도 실제 체결 수익성을 입증하지 않는다. 업종 2개 제한 역시 투자 비중과 상관관계를 관리하는 포트폴리오 모델을 대체하지 않는다.

## 검증 범위

모델 관리 검사 14개, 접목 검사 18개, 기존 엔진 검사 30개, Python 검사 40개, 검증 통합 검사 8개를 통과했다. Windows PowerShell에서 저장/잠금 검사를, PowerShell 7에서 통합 검사를 실행했다. 웹은 JavaScript 구문·차단 사유 연결을 검사했으며 시각적 렌더링 검사는 아니다.

독립 원천 재수집 30종목은 조회 실패 0건, 분석 가능 28건, 일봉 수 부족 또는 중복으로 제외 2건이었다. 제외 자료를 정상 분석으로 포장하지 않는다. 최종 기존 엔진 재생성 수치와 모델 해시는 별도 실행 결과 JSON에 기록한다.
