# 실제 가격 요인 학습: 2026-10-02

`tools/medium_learning.py`는 기존 키움 Windows 프록시의 `/history/{code}/{market}`를
연결해 과거 수정주가·시가·저가·거래량과 KOSPI/KOSDAQ 지수를 수집합니다.
기존 후보 26종목과 사용자 예시인 SK하이닉스를 합쳐 27종목을 수집했고 실패는 0건입니다.
최대 600거래일 자료에서 당일 미완성 봉을 제외했습니다. 최초 60거래일을
요인 계산에 사용하며, 거래소 지수의 거래일 중 종목 봉이 빠지면 해당 학습 자료를 배제합니다.

학습 요인: 5·20·60일 수익률, 20일 변동성, 20일 평균 대비 가격,
거래량 증가 비율, 시장 20일 수익률, 시장 대비 상대수익률.
현재 후보군을 과거에 적용하므로 생존·선택 편향은 해결되지 않았습니다.
과거 실적·수급·HBM을 최신 수치로 소급 입력하지 않습니다.

20·40·60거래일 뒤 다음 거래일 시가 진입 대비 순수익과 시장 초과수익을 계산하고
각각 양수 여부를 정규화 로지스틱 회귀로 학습합니다. 학습/확률 보정/최종 검증은
시간순 60/20/20 비율이며, 앞 구간의 결과 관측 종료일이 뒤 구간 시작일에 닿으면
앞 구간에서 제외합니다. 스케일링은 학습 자료로만 수행하고 확률 보정은 별도 구간으로
수행합니다. 최종 검증은 동일 날짜 종목을 같은 비중으로 묶고 보유 기간의 겹침을 제거합니다.
이 절차가 통계적 독립성을 입증하는 것은 아닙니다.

기존 target10 holdout이 시작된 2026-08-28 이후에 종료되는 1,863개 라벨은 배제했습니다.
최종 학습 자료는 37,272개 종목·날짜·기간 행입니다. 서로 겹치는 행을 독립 표본으로
보고하지 않습니다. 과거 연구자가 이미 본 시장 기간이라는 추가 한계도 있습니다.

| 기간 | 학습 행 | 확률 보정 행 | 최종 검증 행 | 비중복 평가 기간 | Brier 오차 | 단순 상승빈도 기준 오차 |
|---|---:|---:|---:|---:|---:|---:|
| 20일 | 7,202 | 2,077 | 2,665 | 5 | 0.2894 | 0.2484 |
| 40일 | 6,370 | 1,433 | 2,541 | 3 | 0.2887 | 0.2511 |
| 60일 | 5,538 | 806 | 2,417 | 2 | 0.2537 | 0.2446 |

Brier 오차는 낮을수록 좋습니다. 세 모델 모두 기준 대비 개선되지 않았습니다.
20일 선택 종목의 순수익 평균은 0.1685%, 비용을 0.30%에서 0.60%로 늘리면 -0.1315%입니다.
검증 구간에서 거의 모든 종목이 0.55 선택 확률을 넘었으므로 높은 수익률이
선별 능력이나 추가 예측력을 입증하지 않습니다. 40/60일 평균 수익이 양수여도
검증 기간 수와 확률 정확도가 부족해 모두 반영 보류입니다.

시장 초과수익에 대한 공통 Ridge 회귀와 종목별 잔차 회귀를 별도로 계산했습니다.
종목별 잔차는 공통 모델에 최대 25%만 혼합하며, 학습 행 120개 미만 종목은 개별 모델을
만들지 않습니다. 26종목 × 3기간 × 9계수(절편 포함) = 702개 계수를
`reports/factors.db`의 `learned_sensitivities`에 보존했습니다.
정규화 기준과 모델·데이터·코드 지문은 `sensitivity_models`에 저장합니다.
계수는 상관된 요인을 포함한 통계적 조건부 관계이며 인과 효과가 아닙니다.
HBM 수요·공급·가격에 대한 민감도를 학습한 것은 아닙니다.

결과: `reports/medium-learning/runs/20261002-v1/`
원본 가격, 종목군, 학습 행, 정책·코드 지문, 최초 학습 소스, 모델,
확률 보정 계수, 최종 검증 예측을 보존합니다. 원본 소스와 데이터 지문을 확인했습니다.
이미 평가한 run은 덮어쓰거나 재학습하지 않습니다. 같은 검증 기간으로 가중치를
반복 조정하지 않습니다. 새 정책의 승인은 새로운 미사용 기간이 필요합니다.

연결: `learning_bridge.ps1`이 연구 결과를 종목 근거에 연결합니다.
미래·24시간 이상 지난 결과는 이용 불가이며, 파일의 productionEnabled/scoreAdjustment
값으로 승인 조건을 우회할 수 없습니다. 추천 점수 반영은 현재 항상 0점입니다.
추후 검증을 통과해도 ±5점 상한과 기존 엔진 대비 추가 성과 검증이 필요합니다.
학습 데이터에 현재 추천 엔진의 과거 요인값이 충분하지 않아 그 비교는 아직 수행하지 못했습니다.

로컬 `/api/medium-learning`, Cloudflare 읽기 경로, 인증된 업로드 dataset을 추가했습니다.
대시보드는 학습 기간별 확률오차와 반영 보류를 표시합니다. 실행 중인 프록시 재시작과
Worker 배포 전에는 새 경로가 운영 서비스에 반영되지 않습니다. 매 갱신마다 자동 재학습하지
않으며, 학습 완료 시점의 연구 예측을 현재 시세의 확정 확률로 사용하지 않습니다.

실행 예:

```powershell

.\.venv\Scripts\python.exe tools\learning_store.py --run reports\medium-learning\runs\20261002-v1
```

HBM/메모리 가격·고객사 물량은 미연결입니다. 유료 구독은 진행하지 않았습니다.
