# 순수익 10% 목표 연구 모델

구현일: 2026-09-20. 버전: `target10-first-passage-v1`.

## 목표와 사건 정의

실제 이용 가능한 추천 스냅숏 이후 다음 거래소 거래일 시가로 진입한다고 가정한다. 첫 1·2·3거래일 각각에 대해 다음 확률을 함께 출력한다.

- 비용 차감 +10% 목표에 손절보다 먼저 도달할 확률
- 손절에 목표보다 먼저 도달할 확률
- 그 시점까지 둘 다 도달하지 않을 확률

세 확률의 합은 1이다. 목표·손절 누적 확률은 기간이 늘어날수록 감소하지 않는다. 목표가에 닿은 후 가격이 떨어져도 이미 청산된 거래의 수익은 바뀌지 않는다. 목표/손절이 없으면 각 기간의 종가로 평가한다.

목표가격은 다음 식으로 계산한다.

`entry = nextOpen × (1 + entrySlippage)`

`target = entry × (1 + (10 + roundTripCostPct) / 100) / (1 - exitSlippage)`

왕복 비용 0.35%, 편도 슬리피지 KOSPI 0.10%·KOSDAQ 0.20%는 기존 엔진의 가정이다. 시점별 세금·수수료나 실제 체결에서 검증된 비용 모델을 뜻하지 않는다. 계산 목표가는 연속 가격이며 실제 호가단위·체결량·가격제한폭 검증은 남아 있다. 현재가 기반 화면 목표가는 예시이며 다음 시가가 확정되면 다시 계산해야 한다.

손절률은 추천 시점의 최근 변동성 ×1.35를 2.8~5.5%로 제한한다. 20일선 이격 10% 이상 또는 장중 등락률 8% 이상이면 상한을 4.2%로 줄인다. 기존 변동성 정책을 고정해 사용했으며, 검증 구간을 보고 손절률을 조정하지 않았다. 갭 손절은 손절가가 아닌 더 불리한 시가로 체결한다. 시가에서 목표에 도달하면 그 이후 저가보다 먼저 청산된 것으로 처리한다. 일중 고가·저가만으로 순서를 모를 때는 손절 선도달로 분류한다.

## 입력과 모델

`reports/pit-snapshots`의 실행 파일명 기준 날짜별 첫 스냅숏을 먼저 선택한다. 스냅숏의 생성/기준시각과 포함 종목의 수집시각 중 가장 늦은 시각을 정보 이용 가능 기준으로 삼는다. 가격 결과를 보고 스냅숏을 선택하지 않는다. 같은 다음 진입일·시장·종목이 여러 번 나오면 가장 이른 기록만 사용한다.

입력은 저장된 RSI, 20일선 이격, 최근 변동성, 거래량 급증 여부, 외국인·기관 순매수 비율, 평균 거래대금, 20일 상승률이다. 거래량 급증은 현재 저장 스키마의 boolean 필드다. 기존 상승확률·단기점수를 새 모델의 입력이나 정답으로 사용하지 않는다. 필수 지표가 누락된 기록은 현재 값으로 채우지 않는다.

초기 모델은 학습 자료에서 중앙값/IQR로 스케일을 맞춘 뒤 가까운 100개 과거 사례의 7개 사건 범주(목표 D1/손절 D1/목표 D2/손절 D2/목표 D3/손절 D3/미도달)를 집계한다. 전체 학습 빈도 20건 분량을 더해 극단적인 소표본 추정을 완화한다. 그 분포에서 기간별 목표·손절 확률을 산출한다. 기대 순수익도 같은 이웃과 전체 학습 평균으로 추정한다. 이는 연구용 경험 확률이며 보정된 확률이라고 주장하지 않는다.

학습 최소 요건은 200건·20개 진입일·목표 및 손절 사건 각 5건이다. 요건을 못 채우면 확률은 null이다.

## 시간순 검증과 저장

가격 수집 전에 최근 25% 날짜를 검증 구간으로 고정한다. 이번 경계는 **2026-08-28**이다. 학습은 3일 평가 종료일이 검증 시작 7일 전보다 이른 사례로 제한한다. 따라서 경계를 가로지르는 정답이 학습에 들어가지 않는다. 일봉 누락·거래정지 구간은 지수 거래일 달력과 비교해 제외하고, 누락된 봉을 건너뛰어 D+3을 늘리지 않는다. 당일 16:00 KST 이전의 일봉은 미성숙으로 처리한다.

수정주가 기준을 확인하기 위해 스냅숏에 저장된 당일 시가와 지금 조회한 동일 날짜 시가를 비교한다. 1% 이상 차이 또는 비교 불가능이면 제외한다. 이는 기업행사 정식 조정기를 대체하지 않는다. 과거 가격이 사라진 종목의 제외가 생존 편향을 만들 수 있으므로 제외 사유를 함께 보고한다.

- `manifest.json`: 사전 고정 정책·특징·원천 파일 해시·검증 경계
- `features.json`: 추천 당시 특징과 원본 종목 필드
- `prices/`: 검증 가격 원천 응답과 수집시각
- `dataset.json`: 비용·갭·목표·손절을 반영한 정답
- `model.json`: 검증 전에 저장한 학습 결과
- `holdout-predictions.json`: 검증 표본별 예측과 실제 결과
- `validation.json`: 성과·제외 사유·원천 해시·통과 여부
- `latest.json`: 현재 추천 후보의 연구용 확률

경로는 모두 `reports/target10/` 아래다. 이미 평가된 holdout은 `build`로 재선택하거나 다시 맞추지 않는다. 정책을 바꿔 반복 시도할 때는 새로운 버전과 진짜 새 기간이 필요하다. 가격 수집 실패는 평가 전에 중단한다. `predict`는 동결된 모델을 현재 자료에 적용할 뿐 학습하지 않는다.

## 통과 기준과 현재 결과

각 기간의 Brier score, 학습 기본 빈도를 사용한 비교 Brier score, 확률 구간별 실제 빈도를 보고한다. 기대 순수익 >0이고 목표 확률 >손절 확률인 진입 가능 후보를 날짜별 최대 3개 선정한다. 선정 거래의 평균 순수익·초과수익·최악 거래·profit factor·날짜 단위 bootstrap 95% 구간을 산출한다. 겹치는 포지션의 포트폴리오 CAGR·Sharpe·최대낙폭으로 해석하면 안 된다.

통과에는 검증 20개 진입일, 목표 사건 10건, 목표/손절 D3 Brier score가 각각 학습 기본빈도보다 개선, 선정 거래 순수익의 신뢰구간 하한 >0이 필요하다. 기준은 결과를 보기 전에 고정했다.

따라서 **운영 매수 추천은 비활성화하고 연구·관망으로 표시**한다. 검증 표본 자체의 8.42%는 특정 종목의 미래 성공 확률이 아니다.

## 운영 연결

`python tools/target10.py build`는 동결·가격 수집·학습·검증을 실행한다. `python tools/target10.py predict`는 현재 후보를 재평가한다. 추천 생성이 끝나면 predict를 실행하고 `/api/target10`과 웹 대시보드의 독립된 연구 영역에 결과를 제공한다. 다른 추천 스냅숏의 확률이 섞이지 않도록 원본 파일 해시와 결과 나이를 확인한다. Android 화면 연동은 이번 변경에 포함하지 않았다.

실제 매수 후보 전환 전에는 새 기간의 전진 검증, 데이터 품질/공표시각 보강, 수급 인증 안정화, 실측 비용·호가·기업행사 검증이 필요하다. 이번 검증은 **새 모델의 학습에 쓰지 않은 구간**이며, 과거에 사람이 해당 기간이나 다른 전략 성과를 본 적이 없다는 사실까지 증명하지는 않는다. 원천 전체의 발표시각 아카이브도 아직 없다.

검증 원칙 참고: [scikit-learn 시간순 분할](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.TimeSeriesSplit.html), [확률 평가와 calibration](https://scikit-learn.org/stable/modules/calibration.html). 본 구현은 날짜별 분할·정답 종료일 제외를 직접 수행하며 sklearn에 의존하지 않는다.
